# CAD 工作流改进计划

日期：2026-09-18。范围：项目基础设施与协作方式；不自动修改已交付的 GO2 模型。

## 目标与取舍

保留 build123d 离线建模和 Fusion 活模型路线。优先解决对象识别、需求误读、参数联动和交付判定；暂不整体迁移到 CadQuery/FreeCAD，不承诺换内核接口能够恢复 STL 丢失的精确几何。

新建规则零件走 CAD IR → 确定性生成器。现有模型加装优先在 Fusion 读取选中对象和标注草图。STL 只作为网格参考时，应报告拟合误差；截图描点不能冒充精确安装孔位置。

交互只补充缺失问题，不每轮重新问完整问卷：

1. 本轮目标：位置预览、快速样式或最终交付？
2. 参考对象和标注：当前选择、组件实例、草图或已确认坐标？
3. 固定约束：原参考件、安装面、内部空间、总高等哪些不可改变？

位置不明时执行：读取 → 候选标记 → 用户确认/调整 → 重新读取 → 建模。

工具目标（首版支持范围见上节）：

- `read_selection`：返回文档身份、实例路径、单位、局部/装配变换、对象类型与引用。
- `read_annotations`：提取圆、点、轮廓、尺寸、投影/构造属性；区分定位标记与加工轮廓。
- `preview_change`：在独立命名空间创建孔中心 H1、开口 O1、方向和尺寸提示，必要时显示半透明包络。
- `apply_confirmed_change`：只应用当前已确认的计划；引用失效、相关几何变化时拒绝沿用旧定位。

引用使用文档+实例路径+entityToken解析+几何复核；不能比较 token 字符串判定身份，也不能假定 STEP 重导入后仍有效。歧义时提供候选，不自动选择最近实体。

预览草图可供用户编辑；Custom Graphics 用于临时包络及文字。标注/包络不进入制造清单。默认不改原模型几何；完成后仅清理本任务创建的预览，不删除用户草图。

验收：在重名组件、多实例、旋转实例和重新导入模型中不静默选错目标；修改预览草图后，最终孔轴与最后确认的圆心/法向一致；圈选大圆不会自动扩孔。

## P1：统一计划与执行可靠性

新增任务计划层，位于现有 CAD IR 之前，不立即破坏现有 JSON Schema。至少包含：

| 字段 | 含义 |
| --- | --- |
| target / reference | 文档、组件实例、对象绑定、源文件版本或摘要 |
| frame / units | 基准面、法向、原点、方向、统一 mm |
| operations | 修改类型、目标特征、参数 |
| provenance | 数值来自用户、模型测量、标注或建议值 |
| invariants | 禁止改变的对象、安装面、尺寸和范围 |
| unresolved | 必须补充的尺寸和位置 |
| confirmation | 预览版本、确认内容及相关几何指纹 |
| validation / exports | 检查等级和制造实体白名单 |

Fusion 与 build123d 各有能力表；不支持的特征在执行前报告。支持经过白名单解析的尺寸表达式和依赖图，禁止任意 eval。将项目脚本中的孔径、孔位、厚度与特征真实关联，避免仅创建参数表。

RPC 增加任务 ID、阶段状态、超时与状态查询；Fusion 写操作串行。超时不自动重复执行修改。记录已创建对象以支持局部恢复；测试跨阶段失败，不能假定每次 API 事务能撤销整个任务。

输出写入独立构建目录，最终检查后发布交付清单；旧版保留，明确本次成功/失败。失败不宣布旧文件为新交付。每个制造件独立导出，参考模块用显式角色排除，不能只看可见性。

验收：改盖厚时按指定方向变化且固定接合面不动；移动单孔不重建全部参考件；超时重连不重复打孔；受保护参考件修改前后几何一致。

## P2：分层快速模式与检查

| 模式 | 输出 | 必须检查 | 可延后 |
| --- | --- | --- | --- |
| 定位预览 | 标注、轮廓、包络 | 目标、单位、坐标、范围 | 实体布尔、细节、完整干涉 |
| 快速样式 | 简化可视几何 | 构建状态、主要尺寸、明显越界 | 小圆角、紧固细节、详细间隙 |
| 最终交付 | 完整实体及 STEP | 基础几何、需求尺寸、接口、相关干涉、导出清单 | 不省略约定检查 |

当前 CLI 提供 `draft/final`，位置预览通过 Fusion Workflow 实现，没有 CLI `--mode preview`。预览确认不等于制造验证。预览与最终模型必须共用计划和定位数据，不能独立摆放模块拼图。

先记录各阶段耗时，再优化最慢环节。缓存按源几何版本、参数、生成器和内核版本失效。优先只读取选择区域、延迟复杂布尔、局部重算、减少额外格式导出；Fusion 文档变更不并行。

验收：预览和最终版本关键基准/孔轴一致；最终检查可以识别本次出现的盖厚联动导致 C 模块与角柱相交；无变化的区域不反复检查。

## P3：几何识别与后端比较

改进 STEP 检查：同轴面按轴线与半径聚类，结合连通性辨识孔/沉孔/沉头孔；保存轴向范围而非只用 Z 范围。直径不能推断已存在螺纹。每个不确定判断记录依据。

STL 路线先提取安装接口：单位、安装面、孔轴和截面；检查拟合残差和覆盖范围。可评估 Open3D 配准，但它不能决定新零件的安装意图。规则孔和贴合曲面采用不同的误差标准，由制造要求确定。

用相同输入对比 build123d、CadQuery；仅在需要独立开源桌面时评估 FreeCAD。样本覆盖盒体、旋转实例加装、多孔定位、STL 基准提取。记录耗时、失败率、误差、用户纠正次数，不凭库名称决定替换。

## 用户输入示例

> 快速预览。以当前选择的背板顶面为安装面，按“安装孔位”草图定位。先显示盒体包络和孔中心，等我确认。原背板不修改，最终只要 STEP。

> H1 沿草图 +X 移动1.5 mm，孔径不变。盖板向上增厚2 mm，底面固定。

圈选草图建议名为“定位标记_H1”；精确加工轮廓名为“加工轮廓_H1”。命名只是帮助理解，操作仍需关联实际几何。
